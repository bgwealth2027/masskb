# 知识碎片网交互原型

这是给视觉审核看的独立页面，放在 `prototypes/knowledge-network/`。它不替换 `GET /` 的查询页，不改 Python 检索、接口、Compose 或版本，也不会在打开时请求 MassKB。

页面固定标明：**示例数据/交互原型，未接真实知识库**。图上的电流是：**示例关联回放，非后端实时推理**。

## 怎么打开

- 双击同目录的 [`standalone.html`](standalone.html)。库、样例和脚本都内联在这一个文件里，避免用 `file://` 打开时再去读旁边的文件。
- 或者用任意静态服务器打开 [`index.html`](index.html)。脚本使用相对路径，因此站点挂在域名根或项目站 `/masskb/` 下都能找到 `vendor/`、`sample/` 和 `src/`。

预期的 GitHub Pages 项目站地址形如 `https://bgwealth2027.github.io/masskb/`。仓库目前没有启用 Pages，工作流也没有运行过。这个地址未经验证，不能当作已经可打开的入口。审阅通过之后，需要另行授权两件事：在仓库设置里把 Pages 来源选为 GitHub Actions，再手动运行 `deploy-pages`。工作流只在合并到 `main` 之后才会出现在 Actions 列表里。

## 画面

中央是力导向的知识碎片网。文档是圆角矩形，分块是圆，人物是菱形，概念是圆角方块。三份虚构文档各自成团。背景边用低亮蓝青，命中和电流用暖橙。底色是石墨色。

样例边只有三种，都表示结构，不表示因果：

| 边 | 方向 | 含义 |
| --- | --- | --- |
| `HAS_CHUNK` | 文档 → 分块 | 包含 |
| `NEXT_CHUNK` | 前一分块 → 后一分块 | 顺序 |
| `MENTIONS` | 分块 → 人物或概念 | 提及 |

样例不使用 `ALIAS_OF`。市集分块会提及“开放日”，所以背景里有一条指向该概念的边；回放不会为了把两篇文档连起来而反向走这条边，也不会新造一条边。

## 预置问题

匹配只认下面的完整问法。页面会忽略首尾空白和末尾问号，不按词义搜索。对不上就明确提示，不点亮节点，也不生成答案。

| 问题 | 回放 |
| --- | --- |
| 图书馆开放日几点开始？ | 种子“开放时间”点亮，再沿后一分块和提及分叉 |
| 谁负责儿童阅览室？ | 从“儿童阅览”分出三条结构边 |
| 读者指南包含哪些分块？ | 从文档沿 `HAS_CHUNK` 分到三个分块 |
| 社区园艺什么时候浇水？ | 只点亮园艺备忘，不连图书馆 |
| 开放日时间和浇水时间 | 两个种子各自点亮，中间没有边 |
| 量子纠缠的实验装置型号 | 无匹配示例 |

电流按有向边走到哪，哪个节点就点亮。播完后证据子图留在图上。暂停停住当前这一步，已经点亮的节点和已经走过的边保留。重播从头再走。清除只去掉点亮，输入框里的问题还在。

“减少动画”以及系统的减少动态效果，会跳过电流，直接显示和播放结束相同的证据子图。结果列表和路径可以用键盘上下移动，用来代替画布。窄屏时图画在上，结果和详情在下。

节点选中后，右侧显示示例正文、来源、样例里的结构关系，以及从种子走到该节点的路径。图、结果和详情共用同一次选择。

## 数据与回放是分开的

- `sample/graph.js` 只放虚构节点、结构边和预置问题。
- `src/replay.js` 负责匹配和回放。它只走图里已经存在的 `HAS_CHUNK`、`NEXT_CHUNK`、`MENTIONS`，忽略 `ALIAS_OF`。
- `src/app.js` 只负责画布和操作。

`POST /search` 今天返回的是扁平命中，可以附带前后分块 id，打开图扩展时还可以带 `graph_via`。那不是完整子图，这个原型没有调用它，也不能把它当成图数据。

以后如果接入真实知识库，需要在调用方可见范围内单独提供 `nodes`、`edges`、`evidence`、`seed`、`expanded` 和 `path`，并用 `visibility` 说明这次能看见哪些文档和节点。回放仍然只能沿这些数据里真实存在的有向边。
